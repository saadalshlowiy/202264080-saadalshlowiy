# AI Usage Report

### Tools Used & Use Cases
* **Gemini & ChatGPT:** Used for logic architecture, debugging, and advanced JavaScript structuring throughout the assignment iterations. Specifically, I utilized them to figure out how to combine filtering logic with sorting logic simultaneously on DOM nodes, and to structure the `IntersectionObserver` logic for scroll animations.
* **GitHub Copilot:** Assisted with rapid code completion within the IDE, generating boilerplate HTML, CSS variables for the theme toggle, and the Regex code needed for the email validation in the contact form.

### Benefits & Challenges
* **Benefits:** AI significantly accelerated the process of understanding how to interact with the GitHub REST API. Instead of hunting through documentation for the correct endpoint, the AI provided the exact `fetch` syntax. It also saved substantial time on repetitive typing when setting up the CSS grid layout.
* **Challenges:** Initially, the AI suggested complex frameworks (like React) or overly heavy animation libraries for state management and sorting. I had to prompt it carefully to stick to Vanilla JavaScript to meet the assignment requirements and maintain a lightweight performance footprint.

### Learning Outcomes
I learned how to manage DOM states much more effectively. Seeing how the AI structured the `sort()` function on an array created from a `NodeList`, and then appending those elements back into the DOM to reorder them without reloading the page, was a major technical takeaway. I also learned how to implement an `AbortController` to cleanly timeout network requests, preventing the UI from hanging if an API goes down.

### Responsible Use & Modifications
AI's suggestions to fit my specific class names, HTML structure, and personal voice. completely rewrote the generated text content to accurately reflect my real-world focus on AWS infrastructure, CCNA certification, and my status as a KFUPM CS student. removed unnecessary, heavy animations suggested by the AI to keep the site clean, performant, and aligned with my custom teal and dark theme.
